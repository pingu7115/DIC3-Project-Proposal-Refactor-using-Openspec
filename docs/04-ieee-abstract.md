**Title—**AI SOC Analyst Agent: An Evidence-Grounded and Escalation-Aware Hybrid Framework for Security Incident Triage

**Abstract—**Modern security operations centers (SOCs) face unprecedented operational strain driven by relentless cyberattacks, stealthy persistent adversaries, and escalating data breach damages. First-line security analysts are routinely overwhelmed by tens of thousands of heterogeneous daily alerts, where true malicious intrusions represent a negligible fraction below five percent, resulting in pervasive alert fatigue, cognitive overload, and delayed incident containment. Existing statistical machine learning approaches classify alerts as isolated tabular feature vectors without capturing holistic multi-stage attack chain causal progression. Conversely, emerging large language model (LLM) autonomous agents suffer from unacceptably high miss rates exceeding forty percent and frequently close investigations prematurely when enterprise telemetry logs are missing. To resolve these structural vulnerabilities, this paper proposes the AI SOC Analyst Agent, an evidence-grounded and escalation-aware hybrid framework for automated security incident triage. The proposed system synthesizes gradient-boosted decision tree (GBDT) statistical modeling with structured MITRE ATT&CK domain knowledge and multi-step LLM reasoning. Within this architecture, the GBDT classifier delivers rapid, well-calibrated posterior probability distributions over true positive, benign positive, and false positive categories accompanied by SHAP feature attributions. An evidence fusion engine dynamically enforces deterministic kill chain high-risk rules and operationalizes the Assume Breach paradigm, proactively escalating ambiguous, conflicting, log-deficient, or high-risk incidents for human expert verification. To ensure rigorous, reproducible, and leak-free assessment, the framework will be comprehensively evaluated across two distinct public benchmarks: Microsoft GUIDE for large-scale real-world incident classification and ExCyTIn-Bench for multi-step SQL log investigation. Baseline comparisons will encompass majority voting, historical heuristic rules, standalone GBDT classifiers, and unaugmented LLMs across multiple evaluation metrics. The project will empirically characterize the Pareto trade-off frontier between miss rate and human escalation rate, significantly improving triage verifiability, operational transparency, and attack technique mapping while effectively mitigating analyst automation complacency.

**Index Terms—**Alert fatigue, evidence fusion, human-in-the-loop, incident triage, large language models, MITRE ATT&CK, security operations center.
