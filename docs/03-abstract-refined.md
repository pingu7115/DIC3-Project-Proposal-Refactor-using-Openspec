## 第一節：A to F 加強版專業摘要

**【A. Attention Getter】** 資安攻擊規模與破壞代價持續攀升。國安局報告指出，2025 年中共對我關鍵基礎設施網路侵擾日均達 263 萬次，年增 6% [23]；IBM 2026 年報告顯示，全球資料外洩平均成本創 499 萬美元新高，平均處理耗時 247 天 [14]；Mandiant 指出攻擊者潛伏期中位數達 14 天，間諜活動更高達 122 天 [15]。第一線資安維運中心（SOC）每天面對數萬則海量告警，真實攻擊卻不足 5% [2]，形成嚴峻防護挑戰。

**【B. But】** 海量告警引發嚴重告警疲勞，使分析師容易漏看真實進階持續性威脅 [8][24]。現有機器學習分級多依賴靜態特徵比對，欠缺攻擊鏈整體因果脈絡 [1][7]；前沿 tool-using LLM 調查代理人漏判率至少 40.4% [3]，在查無紀錄時更易過早誤判結案 [3]。此外，過度依賴黑箱自動化將削弱批判性監控，誘發嚴重的「自動化自滿（Automation Complacency）」與決策偏誤 [12]。

**【C. Cure】** 為突破上述結構性困境，本專題提出結合機器學習分級、MITRE ATT&CK 領域知識本體與大語言模型脈絡推理的 AI SOC Analyst Agent 智慧代理人系統。系統嚴格落實 Assume Breach 與非對稱錯誤成本原則，針對事件提供具備結構化證據鏈、高可解釋性且「知道何時該主動交由人審查」的 TP/BP/FP 分級與處置建議。

**【D. Development】** 系統整合八大模組：以 GBDT（LightGBM）快速處理百萬級事件並產出經校準的 TP/BP/FP 機率與 SHAP 歸因；以 Chroma 向量庫檢索 ATT&CK 技術本體與 NIST SP 800-61 Rev. 3 指引；以 LLM 進行 ReAct 多步調查；最終由證據融合模組綜合判斷，於低信心、衝突、證據不足或高風險時主動升級人工複核。

**【E. Experiments】** 本專題將以微軟百萬級實證資料集 GUIDE 評估三分類準確度，並以 ExCyTIn-Bench 評估 SQL 日誌調查能力。實驗規劃對比多數類別、歷史規則、純 GBDT 與純 LLM 四大 Baseline，依事件與組織實施嚴格防洩漏切分，重點評估 Macro-F1、TP 漏判率與人工升級率，並以消融實驗驗證各模組增益。

**【F. Expected Outcomes】** 本專題目前處於 Proposal 階段，尚未進行任何實驗。預期成效包含：（1）融合架構之 TP 漏判率將顯著低於純 GBDT 與純 LLM Baseline；（2）成功繪製漏判率與人工升級率之 Pareto 權衡曲線，提供可調門檻 τ；（3）顯著提升 ATT&CK 對應正確性與報告可解釋性。實際結果將於期末報告完整呈現。

## 第二節：預期貢獻與學術價值

### 2.1 預期貢獻（Expected Contributions）
依據專案計畫書 §2.6 所列之五大具體研究貢獻：

1. **系統架構貢獻（System Architecture）**：設計並實作包含 ① 到 ⑧ 的模組化代理人架構，提供清晰的職責分離與介面合約，支援開源生態與企業既有資安工具無縫擴充（見 §2.6.1、§5.1）。
2. **決策方法貢獻（Decision Methodology）**：提出演算法 Algorithm 1（SOC Triage Agent）與 Algorithm 2（證據融合與主動升級），將 Assume Breach 與錯誤成本不對稱思維轉化為嚴謹的數學機率加權、安全重標註與高風險攻擊鏈規則邏輯（見 §2.6.2、§5.3）。
3. **實證評估貢獻（Empirical Evaluation）**：將於百萬級真實事件資料集 GUIDE 與動態 SQL 調查環境 ExCyTIn-Bench 雙重公開基準上驗證，實施嚴格防洩漏切分並透過消融實驗量化各模組獨立增益（見 §2.6.3、§5.4）。
4. **領域知識貢獻（Domain Knowledge）**：系統化整理 SOC 領域五大思維模式、三大爭論與十大核心問題，搭建學術演算法與工業現場資安維運實務的溝通橋樑（見 §2.6.4、§4）。
5. **規範治理貢獻（Specification & Governance）**：導入 OpenSpec 規格驅動開發（SDD），提供完整變更規格、測試場景與標準化自動營運腳本（`startup.sh`、`ending.sh`），顯著提升專案成果的可重現性與工程規範性（見 §2.6.5）。

### 2.2 學術價值（Academic Significance）
本研究在資安人工智慧領域之學術意涵與理論價值具體體現在以下四個面向：

1. **將資安防禦思維轉化為可驗證的演算法規則**：將資安維運中抽象的「Assume Breach（假設已遭入侵）」與「錯誤成本不對稱」兩大思維模式，具體轉化為可審計、可驗證的數學與規則演算法（如 Algorithm 2 的高風險規則 R1–R5 與 $\tau_{safety}$ 安全重標註機制），從演算法層面落實非對稱代價防護，克服傳統黑箱模型在資安極限情境下缺乏安全底線護欄的理論缺陷（見 §1.1、§4 Q1、§5.3）。
2. **結合 GBDT、ATT&CK 知識與 LLM 推理的混合分級框架，回應 §3.4 Research Gap**：針對現有研究中純機器學習模型欠缺攻擊鏈脈絡解釋（如 [1]、[7]），以及純 LLM 代理人漏判率高達至少 40.4% 且易在查無紀錄時過早結案（如 [3]）的瓶頸，提出兼顧統計校準與語意推理的混合架構，並以可解釋的 Pareto 取捨曲線回應「全自動 vs 人機協作」的學術爭論（見 §2.5、§3.4、§4 Q2）。
3. **以 GUIDE 與 ExCyTIn-Bench 兩個公開基準設計跨資料集評估**：同時在微軟百萬級真實事件資料集 GUIDE 與多步 SQL 調查環境 ExCyTIn-Bench 上設計嚴格的依事件、組織與時間分割之評估計畫，正面回應綜述文獻 [8] 所指出的長期缺乏公開可重現評估標準的學術缺口（見 §3.2.1 [8]、§3.4、§5.4）。
4. **以 OpenSpec 規格驅動開發提升系統可重現性與防自滿機制**：透過 OpenSpec 將系統需求、行為規格與演算法設計進行嚴格的版本化契約治理，並在輸出端強制保留結構化證據鏈，回應人因文獻 [12] 與 [26] 揭示的「自動化自滿（Automation Complacency）」風險，為後續 AI Agent 在真實維運環境的部署提供高可驗證性的治理典範（見 §2.6.5、§3.2.5 [12]、§3.4）。

## 第三節：重點摘要（連續精煉版）

面對我國國安局最新統計中共對我關鍵基礎設施每日平均侵擾達 263 萬次，以及 IBM 2026 年度報告揭示全球企業資料外洩平均成本創 499 萬美元新高與事件處理週期長達 247 天的嚴峻威脅，第一線資安維運中心（SOC）面對每日數萬則零散告警，陷入嚴重的告警疲勞，而真實惡意入侵往往不足百分之五。現有微軟 CGR 等機器學習分級方法依賴靜態特徵比對，缺乏對多階段攻擊鏈推進因果脈絡的理解；而前沿語言模型調查代理人在無結構化護欄下漏判率高達至少百分之四十點四，且在查無紀錄時最易過早誤判無害結案，黑箱自動化更易引發分析師自動化自滿與監控偏誤。為此，本專題提出 AI SOC Analyst Agent，創新結合 GBDT 統計分類、MITRE ATT&CK 領域知識本體與大語言模型脈絡推理。系統透過 LightGBM 快速輸出校準後之 TP、BP、FP 機率分佈與 SHAP 特徵歸因解釋，以 Chroma 向量資料庫檢索攻擊技術與 NIST SP 800-61 處置流程，並由證據融合模組嚴格執行五大高風險攻擊鏈硬規則。當模型信心不足、多源結論衝突、證據缺失或觸發高風險規則時，系統主動升級交由人類專家複核。評估規劃將採用 Microsoft GUIDE 百萬起真實事件與 ExCyTIn-Bench 雙重公開基準進行無洩漏驗證，預期將顯著降低真陽性漏判率，並繪製漏判率與升級率之 Pareto 權衡曲線，達成兼具高安全性與可解釋性的智慧協同分級。
